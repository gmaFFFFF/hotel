# Бизнес-ограничения

## Общие сведения

В ходе [валидации](../validations.md) проверяется внутренняя непротиворечивость команды
и формальная корректность её атрибутов.
При проверке бизнес-ограничений проверяется допустимость выполнения формально корректной команды.

Например, при создании заказа на стадии валидации проверяется, что количество товара больше 0,
а на стадии проверки бизнес-ограничения — не превышение складских запасов.

## Использование

Для проверки бизнес-ограничений, которые должны удовлетворяться при исполнении
`gmafffff.starterKit.Messaging.BusinessCommand`,
необходимо определить классы, реализующие интерфейс проверки бизнес-ограничения —
`gmafffff.starterKit.BusinessLogic.IBusinessConstraintCheck`.

Одной команде может соответствовать множество бизнес-ограничений.

## DI

Регистрация бизнес-ограничений в контейнере DI осуществляется во время вызова
метода расширения `IServiceCollection.AddBusinessLogic`.
