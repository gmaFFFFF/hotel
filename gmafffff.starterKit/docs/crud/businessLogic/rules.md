# Бизнес-правила

## Общие сведения

В ходе [валидации](../validations.md) проверяется внутренняя непротиворечивость команды
и формальная корректность её атрибутов.
При проверке бизнес-правил проверяется допустимость выполнения формально корректной команды.

Например, при создании заказа на стадии валидации проверяется, что количество товара больше 0,
а на стадии проверки бизнес-правила — не превышение складских запасов.

## Использование

Для проверки бизнес-правил, которые должны удовлетворяться при исполнении
`gmafffff.starterKit.Messaging.BusinessCommand`,
необходимо определить классы, реализующие интерфейс проверки бизнес-правила —
`gmafffff.starterKit.BusinessLogic.IBusinessRule`.

Одной команде может соответствовать множество бизнес-правил.

Регистрация бизнес-правил в контейнере DI осуществляется вызовом `AddBusinessRules` —
метода расширения `IServiceCollection`.
